Pocket PCB Radio

Expand

This is my custom FM radio receiver PCB for listening to classical music on Saturday mornings, and winter holiday tunes.

Features:

  • The Si4704-D60 RF FM receiver IC
  • A STM32G030 microcontroller
  • An audio output port for headphones/speakers
  • Seek/tune functionality and volume control
  • Battery powered (4 x AAA)
  • PCB antenna
... which is really all I wanted from a radio!

Mini Maglev: Linear Induction Motor (Capstone Part I)

Expand

Part 1 of 2 of my capstone project, which is to build a miniature maglev train. The first part involved building a custom linear induction motor from scratch, which propels the train.

  • I designed and built the test stand and 3 phase driver PCB in the video below
  • I also wrote an Space Vector PWM algorithm + Variable Frequency Drive firmware to test the driver
  • ... And worked on part of the Field-Oriented Control firmware


My favorite part was, of course, designing the linear induction motor driver PCB, which features:
  • Three half bridges using high/low side gate drivers and NMOSFETs. The driver is capable of 5A continuous and 10A peak current at 100V.
  • Inline current sensing with 3mΩ shunt resistors and sigma delta isolation amplifiers. Current sense bandwidth reaches 100kHz but we sample at closer to 20kHz.

My design files can be found in our team github repository by the user peanat-byte. There is much to be improved in this driver design, for example, reducing the inductance of the switch node - gate drive output loop. Plenty of optimizations to make for revision 2!

Autonomous Actuated Parachute System

Expand

The autonomous actuated parachute system is one of the projects that I led on the Uncrewed Aircraft Systems student design team.

As a lead, I did a fair bit of project management, but still dove into some technical work:

  • Defining the system: A master controller (ESP32) that retrieves information from the aircraft and communicates target locations to individual parachute controllers, which are then released and steer towards the targets.
  • Prototyping the parachute "flight controller" boards, which involved integrating sensors (GPS, IMU, barometer, and encoders) and steering servos.
  • Writing firmware that enables the master controller to talk to the aircraft flight controller (Mavlink protocol) and to the Raspberry Pi performing image recognition (UART) to retrieve aircraft sensor data and calculate airdrop locations.

Robot Detective in ROS/Gazebo (ENPH 353 Machine Learning)

Expand

The competition goal for this project was drive a robot in Gazebo simulation with ROS to read clue boards and avoid obstacles.



One fun thing I did do in this project was train a YOLO neural network to detect obstacles. I knew this was a bit overkill (most other teams used color thresholding or frame differencing) but I wanted to try something new. A few hundred manually labelled images later, I got obstacle detection working surprisingly well!
